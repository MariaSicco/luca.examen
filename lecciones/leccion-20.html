🗺 Diagrama tipo final — dibujalo de memoria
🔑 La secuencia, de memoria
  1. Coeficiente: si el derecho está incluido en el valor, se saca con 100 ÷ (100 + %). Con derecho 10% → 0,90. Si NO está incluido, no se usa coeficiente.
  2. FOB frontera: CIP 50.000 − flete 1.500 − seguro 500 = 48.000 (art. 736). Se valora hasta el lugar de carga.
  3. Valor imponible ≈ 51.189,50 (ajustes). Base imponible = valor imponible × coeficiente = 46.535,86; derecho = base × 10%.
  4. Reintegro: se calcula su base y se compara con la base imponible → se toma la menor. Mermas: 200×6 L = 1.200 L ÷4 = 300 latas ×2 = 600 USD CIF.
⚠ Acá se desaprueba
  • Usar coeficiente cuando el derecho no está incluido: ahí no corresponde.
  • No restar flete y seguro para llegar al FOB frontera (art. 736).
  • Para el reintegro, no comparar las bases: se toma la menor entre base imponible y base de reintegro.
  • Equivocar la cadena de la merma (litros → latas → dólares).

🎯 Preguntas tipo final (tapá la respuesta)
Oral¿Para qué sirve el coeficiente y cómo se calcula?
Sirve para separar el derecho de exportación cuando ya está incluido en el valor. Se calcula como 100 dividido (100 + porcentaje de derecho). Por ejemplo, con un derecho del 10% el coeficiente es 100/110 = 0,90. Si el derecho no está incluido, no se usa coeficiente.
EscritoCIP Chile 50.000, flete 1.500, seguro 500. ¿FOB frontera?
48.000. Como la exportación se valora hasta el lugar de carga, se restan del CIP el flete (1.500) y el seguro (500): 50.000 − 2.000 = 48.000 (FOB frontera, art. 736).
Trampa¿Cómo se define la base del reintegro?
Se calcula una base de reintegro (restando comisiones y el CIF de importación definitiva) y se compara con la base imponible: se toma la menor de las dos.
